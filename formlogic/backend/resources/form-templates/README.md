# Bundled form starters

One JSON file per template. The filename must match its `id`. These definitions are loaded
at request time by `FormTemplateCatalog`, not compiled into the frontend.

For site-specific additions/overrides use `backend/storage/form-templates/` instead.
See [form template guide](../../../../docs/FORM_TEMPLATES.md) for the format, categories,
disabling defaults and validation commands.
