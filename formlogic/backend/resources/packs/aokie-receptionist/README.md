# Aokie Receptionist

An AI phone receptionist powered by FormLogic Desktop and the Aokie Bluetooth phone bridge: live call console with answer/hang-up/speak controls, automatic call, transcript and SMS records, caller lookup, call summaries, SMS reply drafts and follow-up tasks via starter FormLogic Flows. Includes 10 forms and 1 app.

Edit `pack.json` for the listing, `install.json` for forms, roles, reports and flows, and `projects/` for the Softn workspace and private server actions. Form records use FormLogic’s existing SQLite storage and access controls. No sample personal records or credentials are included.

Live phone, SMS and voice features require a configured OAIY/Aokie connection and approved connector grants. Installing never starts calls or sends messages.
