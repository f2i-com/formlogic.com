# CounterFlow — Retail Store Operations

The operational layer around the till for boutiques and specialty retail: products and suppliers, stock movements, store tasks, staff and returns, with low-stock alerts and a stock-value estimate. Includes 6 forms and 1 app.

Edit `pack.json` for the listing, `install.json` for forms, roles, reports and flows, and `projects/` for the Softn workspace and private server actions. Form records use FormLogic’s existing SQLite storage and access controls. No sample personal records or credentials are included.
